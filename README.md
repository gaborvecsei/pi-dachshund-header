# Dachshund Header for pi

A tail-wagging dachshund startup header for pi. Just so you'll start your day with a smile.

TODO image here

## Install

```bash
pi install npm:pi-dachshund-header
```

Or straight from GitHub:

```bash
pi install git:github.com/gaborvecsei/pi-dachshund-header
```

### Remove

To go back to the built-in header, `pi remove npm:pi-dachshund-header`.

## Notes

- The dog is drawn with 24-bit colors, so it looks best in a truecolor terminal.
